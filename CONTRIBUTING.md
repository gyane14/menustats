# Contributing

Issues and pull requests are welcome.

Before a pull request can be merged, you need to sign the [Contributor License Agreement](CLA.md),
once. [CLA Assistant](https://cla-assistant.io) will comment on your first pull request with a link:
sign in with GitHub and accept. Your signature is stored by CLA Assistant and covers future pull requests.

The CLA lets the project be relicensed or sold later without tracking down every contributor. You
keep the copyright in your work.
